# الزمن الجميل — مطعم أفران

**عرض تشغيل مُعدّ لمالك الموقع.** موقع صفحة واحدة، عربي RTL، بلا أي اعتماديّة خارجيّة.

🔗 **[tihou74.github.io/al-zaman-al-jameel](https://tihou74.github.io/al-zaman-al-jameel/)**

> ⚠️ افتح الرابط مع رقم جديد دائماً — مثل `?v=15` — لتجاوز الكاش.

---

## الهدف

**الممّولون هم أصحاب المشروع.** الطرف الآخر **مالك الموقع**، والغاية إقناعه بمنح الموقع.

فالوثيقة **عرض مستأجر** لا طلب تمويل، وسؤال المالك الحاسم:

> **«هل هذا المستأجر يدفع بانتظام، ويبقى، ويضيف قيمة لموقعي؟»**

النسخة الأولى من البروفايل أجابت على سؤال لم يُسأل — فكانت ٨ صفحات منيو من ٢١، وصفر أرقام. التشخيص الكامل بالأدلّة في [`docs/evidence/`](docs/evidence/) و[`.kiro/steering/project-memory.md`](.kiro/steering/project-memory.md).

## التأثيرات

**الفرن:** اهتزاز حرارة حقيقي بـ`feTurbulence` + `feDisplacementMap` على **منطقة اللهب فقط** (قناع بيضاوي) — فيرتجف اللهب والطوب ساكن. مع هباب وجمر وشرارات ووهج نابض.

**جدار الذكريات:** ١٠ قطع بإطارات بولارويد، كل قطعة بـ`data-depth` مختلف فتتحرّك بسرعة مختلفة مع المؤشّر — عمق مجسّم حقيقي. وتستقيم وتُضاء عند التمرير.

**المشعل:** الصورة مُعتمة ويكشفها ضوء يتبع المؤشّر أو الإصبع عبر `mask-image` متحرّك.

**آلة الزمن:** السنة ترجع ٢٠٢٦ → ١٩٦٥ مع التمرير، وطبقة سيبيا تتكاثف.

**مقدّمة الفيلم:** عدّ تنازلي وخدوش ثم الشعار يَظهر كصورة تُحمَّض. مرّة واحدة في الجلسة، تُتخطّى بأي ضغطة.

**وأيضاً:** قبل/بعد · جولة أفقيّة · ميل ثلاثي الأبعاد · مؤشّر جمرة · أزرار مغناطيسيّة · كشف العناوين كلمةً كلمة.

كلها تتوقّف تلقائياً لمن يفعّل `prefers-reduced-motion`.

## الهويّة

**خطّ واحد: `Alexandria`.** الشعار هو العنصر المخطوط الوحيد ويُستخدم كصورة.

```
#2E4057 كحلي الشعار    #C0392B أحمر      #F4EADA ورق عتيق
#44503A زيتوني          #C9A227 ذهبي      #A3D9B8 نعناعي
#E9E1D2 بيج             #6B7F3F جينجهام   #6F1D24 نبيذي
```

**ستّ نقشات** من البروفايل الأصلي، و**نقشتان مولّدتان بـCSS**: النقاط الذهبيّة (٣ طبقات) والجينجهام الأخضر (خطّان شفّافان متعارضان ⇒ ثلاث درجات كالقماش).

**قاعدة الإيقاع:** لا قسمان متجاوران بخلفيّة متشابهة.

## الأدوات

```bash
# حارس حدّ ٢٠٠٠ بكسل — إلزامي قبل قراءة أي صورة
python3 .kiro/tools/imgguard.py check <file>
```

## ما ينتظر استكماله

**🏚️ صورة الموقع فارغاً** (لـ«قبل/بعد» — أقوى حجّة) · **الأرقام** (مساحة، مقاعد، متوسّط فاتورة، تكلفة، إيراد، تعادل) · **الفريق** (ملاك، شيف، مدير تشغيل) · **إثبات مالي** · **بيانات الموقع ومالكه** · **حسم كتابة الاسم** (`aljameel` أم `aldjameel`) · **مدد التنفيذ** · **موسيقى أطول مرخّصة**
