# الزمن الجميل — مطعم

مساحة عمل العلامة التجارية: الاستراتيجية، الهوية البصرية، البروفايل، المنيو، والعرض التقديمي.

**الحالة:** البروفايل الأول قُدِّم لمالك الموقع ولم يحقّق القبول — نعيد البناء من الأساس.

**الهدف من الوثيقة:** إقناع **مالك الموقع** بمنحنا الموقع.
التمويل مؤمَّن من جهتنا — فالوثيقة ليست طلب تمويل، بل **عرض مستأجر**.
الجمهور هو مالك العقار، وسؤاله ليس "كيف أستعيد مالي؟" بل
**"هل هذا المستأجر هو الأفضل لموقعي؟"**

---

## الخطوة الأولى: ارفع البروفايل الحالي

ضع الملفّات في مجلّد **`inbox/`** — اقرأ [`inbox/README.md`](inbox/README.md) لصيغ الملفّات المقبولة.
المهم: تصدير الصور بحيث **لا يتجاوز أطول بُعد 2000 بكسل** (التفصيل في الملف).

بدون رؤية البروفايل الحالي لا أستطيع تحديد ما الناقص فعلاً — ملاحظة العميل
"ناقص كثير" تحتاج تشخيصاً لا تخميناً.

## حدود البيئة التقنية

هذه قيود حقيقيّة مُتحقَّق منها في هذا الصندوق، وتحدّد ما أستطيع فعله:

| القيد | الأثر |
|---|---|
| لا يوجد أي محوّل PDF (`pdftoppm`, `mutool`, `gs` — كلها غير موجودة) | **لا أستطيع تحويل PDF إلى صور لمعاينته بصرياً** |
| لا ImageMagick ولا Pillow، وPyPI وnpm محجوبان (403) | لا أستطيع تثبيت بدائل |
| `.kiro/tools/imgdown.py` | يصغّر **PNG** فقط (Python خالص) — JPEG لا يُصغَّر |
| حدّ 2000 بكسل لكل بُعد | أي صورة أكبر تُرفض قراءتها ⇒ انظر `inbox/README.md` |

**الخلاصة العمليّة:** أفضل صيغة ترفعها هي **PNG بأبعاد ≤ 2000 بكسل**.

## حدّ أبعاد الصور

```bash
# فحص صورة قبل القراءة (0 = آمن، 2 = متجاوز)
python3 .kiro/tools/imgguard.py check <file>

# تصغير PNG متجاوز
python3 .kiro/tools/imgdown.py <in.png> [out.png] [--max 2000]

# أقصى DPI آمن لمقاس بالبوصة
python3 .kiro/tools/imgguard.py dpi 8.27 11.69
```

التفاصيل الكاملة وحدود كل أداة في [`.kiro/steering/image-dimension-limit.md`](.kiro/steering/image-dimension-limit.md).
