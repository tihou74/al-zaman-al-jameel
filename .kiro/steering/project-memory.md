# الزمن الجميل — ذاكرة المشروع

> ملفّ الحالة الكامل. يُقرأ في كل جلسة فلا نكرّر سؤالاً أو نعيد قراراً.

## ١. الحقيقة الأساسيّة التي تحدّد كل شيء

**العميل هو الممّول.** الطرف الآخر **مالك الموقع**، والهدف **إقناعه بمنح الموقع**.

فالوثيقة **عرض مستأجر** لا طلب تمويل. وسؤال المالك ليس «كيف أستعيد مالي؟» بل:

> **«هل هذا المستأجر يدفع بانتظام، ويبقى، ويضيف قيمة لموقعي؟»**

كل قرار في المشروع يُقاس بهذا السؤال.

## ٢. المفهوم

- **مطعم أفران** — أغلب الأطباق تُخبز: طواجن فخّار، صواني، صاج وفطاير، أرزّ بالفرن
- **الزمن الجميل = زمن لا مكان:** حوض المتوسط في الستينات والسبعينات —
  بيروت، الإسكندرية، نابولي، اليونان، الشام
- **الميكس مقصود ومُعلَن** (قرار العميل الصريح): مزّة شاميّة + مقبّلات إيطاليّة +
  طواجن مصريّة. الجامع هو **الفرن** والزمن والمفارش المربّعة
- الفرن **مكشوف في الصالة**: مشهد ورائحة وثلاث حواسّ تعمل قبل الطلب

## ٧. قواعد العمل المستفادة

### الكاش
العميل رأى نسخاً قديمة **ثلاث مرّات**. القاعدة: **أعطه دائماً رابطاً برقم جديد**
`?v=N`، وزِد `N` في كل دفعة، وحدّثه في `index.html` أيضاً.

### RTL
`translateX` في اللفّ الأفقي يجب أن يكون **موجباً** في RTL — المحتوى الزائد
يمتدّ يساراً فالكشف عنه يتطلّب تحريكاً يميناً. الإشارة السالبة تُخفيه
فيبدو أن «لا شيء يتحرّك». (كان هذا خللاً حقيقياً وأُصلح.)

### اهتزاز الحرارة
يُطبَّق على **منطقة اللهب فقط** عبر `mask-image` + `feDisplacementMap`.
تطبيقه على الصورة كلها يُرجّف الطوب فيفسد الإيهام.
شدّة الإزاحة: اللهب `4.5` مع تمويه `1.9`، والهباب `16–18`.

### الأداء
`background-attachment:fixed` **ممنوع** — يُجبر إعادة رسم الخلفيّة كل إطار
ومع فلاتر SVG العاملة يصير التمرير متقطّعاً.

### الرفع
العميل يرفع إلى **جذر المستودع** لا إلى المجلّد المقصود. **تحقّق من الجذر دائماً**
ثم انقل الملفّات. وسمِّ الملفّات العربيّة بأسماء لاتينيّة (مسارات URL العربيّة تنكسر).

**وأهم من ذلك:** قد يرفع ملفّات بأسماء فيها مسافات أو عربيّة أو **امتداد مزدوج**
(`.mp3.mpeg`) فلا يجلبها `git pull` بشكل سليم. الحلّ المُجرَّب:
`git fetch && git reset --hard origin/main` ثم إعادة التسمية.
وللتحقّق مما وصل فعلاً: `gh api repos/{o}/{r}/commits/{sha} --jq '.files[].filename'`

### التحقّق البصري
الصندوق **بلا خطوط عربية** — فلقطات الشاشة تُظهر العربي مربّعات.
للحكم على التبايُن: **صفحة اختبار بنصّ لاتيني**. وللمكوّنات البصريّة بلا نصّ
(الفرن، جدار الذكريات) اللقطة صحيحة ومفيدة.
وللمعاينة المعزولة: مسارات **مطلقة** + تعطيل `[data-reveal]` (يبدأ `opacity:0`).

### الصوت
لا تشغيل تلقائي — المتصفّحات تحجبه. البدء عند **أول لمسة**، بتصاعد من صفر،
وبمستوى `0.32`، مع احترام اختيار الزائر في `sessionStorage`.

## ٨. الأدوات المبنيّة (في `.kiro/tools/`)

| الأداة | الوظيفة |
|---|---|
| `imgguard.py` | حارس حدّ ٢٠٠٠ بكسل — `check` · `dpi` · `hook` |
| `imgdown.py` | مُصغِّر PNG بـPython الخالص (PyPI محجوب) |
| `pdfpeek.py` | جرد PDF: صفحات، صور، مرشّحات، خطوط |
| `pdftext.py` | استخراج نصّ PDF بفكّ ToUnicode ومعالجة العربية |
| `pdfpages.py` | ربط كل صفحة بصورها |
| `gen_oven.py` | توليد طوب القبّة الشعاعي حسابياً |
| `build_oven_svg.py` | تجميع SVG الفرن |

**قيود البيئة المُتحقَّقة:** لا PDF converter · لا ImageMagick/Pillow ·
PyPI وnpm محجوبان (403) · `github.io` غير قابل للوصول من الصندوق ·
Chrome متاح في `/usr/local/bin/chrome` · `/tmp` لا يبقى بين استدعاءات bash.
