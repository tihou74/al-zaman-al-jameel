# inbox — المدخلات الخام

ارفع هنا كل ما لديك عن المشروع. كلّما زاد ما أراه، دقّ التشخيص.

## ما أحتاجه

1. **البروفايل الحالي** — الذي قُدِّم ولم يُقبل (الأهم)
2. **ملاحظات العميل** إن كانت مكتوبة، أو اكتبها في ملف نصّي هنا
3. **الشعار** إن وُجد — بأي صيغة
4. **صور المطعم**: الموقع، الديكور، الأطباق
5. **المنيو الحالي** أو قائمة الأصناف والأسعار
6. **مراجع تحبّها** — مطاعم أو هويّات بصريّة أعجبتك

## الصيغ: الأفضل والمقبول

| الصيغة | الحالة | ملاحظة |
|---|---|---|
| **PNG ≤ 2000 بكسل** | ✅ الأفضل | أراها بصرياً ومباشرة |
| JPG ≤ 2000 بكسل | ✅ جيّد | أراها، لكن لا أستطيع تصغيرها إن تجاوزت |
| PNG > 2000 بكسل | ⚠️ | أصغّرها بنفسي، لكن ارفع نسخة صغيرة لتوفير الوقت |
| **JPG > 2000 بكسل** | ❌ | لا أستطيع رؤيتها ولا تصغيرها — صدّرها PNG أو صغّرها قبل الرفع |
| **PDF** | ❌ بصرياً | لا يوجد محوّل PDF في البيئة. ارفعه للأرشفة، لكن **صدّر صفحاته PNG** لأراها |
| نصّ / Markdown | ✅ | ممتاز للملاحظات والأسعار |
| DOCX / PPTX | ❌ | لا يوجد LibreOffice — صدّرها PNG أو انسخ النصّ |

## حدّ 2000 بكسل — سبب القيد

قراءة صورة يتجاوز **أيّ** من بُعديها 2000 بكسل تُرفض من النظام، والرفض يأتي
بعد انتهاء العمل كله ⇒ تضيع الجلسة. لذلك القيد صارم لا اختياري.

## كيف تصدّر بأبعاد آمنة

عند التصدير من PDF أو Illustrator أو Canva، اختر DPI حسب المقاس:

| المقاس | أقصى DPI آمن | الأبعاد الناتجة |
|---|---|---|
| A4 (21×29.7 سم) | **171** | ~1414×2000 |
| Letter (8.5×11 إنش) | **181** | ~1538×1991 |
| A3 (29.7×42 سم) | **120** | ~1403×1985 |
| مربّع 20×20 سم | **254** | ~2000×2000 |
| بانر 10×30 سم | **166** | ~664×1992 |

**القاعدة:** `أقصى DPI = 2000 ÷ أطول بُعد بالبوصة`

للحساب السريع لأي مقاس:

```bash
python3 .kiro/tools/imgguard.py dpi <العرض_بالبوصة> <الطول_بالبوصة>
```

**الأسهل من كل هذا:** في أي برنامج تصدير، اختر "تصدير بالبكسل" واضبط أطول
بُعد على **1600** — رقم آمن ومريح للقراءة.
